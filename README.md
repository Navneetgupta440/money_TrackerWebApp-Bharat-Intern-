📌 Overview

The Money Tracker Web App is a full-stack financial management application designed to help users efficiently track their income, expenses, and overall financial health.

This project was developed as part of the Bharat Intern Program, showcasing practical implementation of modern web technologies and full-stack development skills.

It provides a simple, intuitive, and scalable solution for managing personal finances in real-time.

🎯 Key Features

✔️ Add, update, and delete transactions
✔️ Track income vs expenses
✔️ Real-time balance calculation
✔️ Organized transaction history
✔️ Clean and responsive UI
✔️ Backend integration with database
✔️ Secure data handling

🧠 Problem Statement

Managing personal finances manually can be inefficient and error-prone.

This application solves that problem by:

Centralizing financial data
Providing structured transaction tracking
Enabling better budgeting and decision-making

⚙️ Installation & Setup

Follow these steps to run the project locally:

# Clone the repository
git clone https://github.com/Navneetgupta440/money_TrackerWebApp-Bharat-Intern-

# Navigate to project folder
cd money_TrackerWebApp-Bharat-Intern-

# Install dependencies
npm install

# Start the server
npm start
